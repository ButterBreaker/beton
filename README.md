# Бетон : copie hors ligne

Copie publique de l'appli de russe **Бетон**, lue par l'appli Android pour fonctionner sans réseau.

- `index.html` : l'appli (aucune donnée personnelle ; la progression reste dans le téléphone et le compte).
- `version.json` : numéro de version et empreinte SHA-256, vérifiée par l'appli avant toute mise à jour.

Ne pas modifier à la main : ces fichiers sont générés à chaque publication.
